# SpendWise

## Project Title

SpendWise

## Project Description

SpendWise is an interactive personal finance dashboard that helps users set a monthly budget, add expenses, view their total spending, and check their remaining balance.

Users can enter a monthly budget, add expense records with a description, amount, category, and date, and see the dashboard update immediately. The application also provides feedback when the user is within budget, close to the budget limit, or has exceeded the budget.

## Deployment Process Summary

1. Completed the SpendWise project using HTML, CSS, and JavaScript.
2. Created a public GitHub repository.
3. Uploaded the project files to the repository.
4. Created a Netlify account and connected it to GitHub.
5. Imported the SpendWise GitHub repository into Netlify.
6. Used the repository root as the publish directory because the project is a static website.
7. Changed the default Netlify subdomain to a meaningful project name.
8. Made a visible update to the project, pushed it to GitHub, and confirmed that Netlify automatically deployed the update.
9. Tested the live website to ensure the HTML, CSS, JavaScript, forms, buttons, and dashboard updates worked correctly.

## Challenges Encountered During Deployment

One challenge was ensuring that the correct project folder was selected during deployment. Since SpendWise is a static website, the repository root was used as the publish directory instead of a build folder.

Another challenge was confirming that automatic deployment worked. This was solved by making a small visible change to the website, committing and pushing the change to GitHub, then refreshing the Netlify website to confirm that the update appeared.

A further challenge was changing the default Netlify site name. This was solved by opening the Netlify site settings, selecting **Domain management**, and updating the default subdomain to a more meaningful name related to SpendWise.

## Lessons Learned

- GitHub is used to store and manage project files online.
- Netlify can deploy a static website directly from a GitHub repository.
- Continuous deployment automatically updates a live website after changes are pushed to GitHub.
- A static website does not require a build command if the HTML, CSS, and JavaScript files are already ready for publishing.
- Testing a live website is important because a project can work locally but still need checking after deployment.

## How to Run the Project

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Enter a monthly budget and click **Set Budget**.
4. Add expenses using the expense form.
5. View the updated totals and transaction list.
